# Орбита — лендинг дизайнерского светильника (концепт)

Светильник придуман: стеклянное ядро с «туманностью» и лампочкой (нити накаливания) внутри, латунная дуга, кольцо-орбита с луной,
каменное основание с солнечной панелью и кнопкой включения (провода нет).
Тексты — `src/content.ts` (продающие, написаны с нуля).

- Next 16 + SCSS-модули, `u()` из `src/styles/_core.scss` (ДВ 1440 / контент 1280; МВ ≤1023 — колонка 358, поля 16).
- 3D: `src/three/LampScene.ts` — процедурная модель three.js + bloom; `src/components/Lamp.tsx` — фиксированный холст.
  Секции задают сценарий атрибутами `data-stop data-pose="…" data-tone="#hex"`; позы — таблицы DESKTOP/MOBILE в Lamp.tsx.
  Цвет света пишется в CSS-переменную `--tone` (кнопки, акценты перекрашиваются вместе со светом).
- Отделка (латунь/графит/серебро) — событие `orbita-finish`. Выключатель: `orbita-power-set` (запрос) → `orbita-power` (состояние), кнопка на основании (попадание по `bounds.bx/by`) или клик по ядру, `html[data-off]`.
- Вращение руками: мышь тянет (инерция), на телефоне — горизонтальный свайп. Приближение: кнопки «−/+» (`orbita-zoom-set`),
  Ctrl/⌘ + колесо над светильником, щипок. Звёзды расступаются у курсора (`state.mx/my`).
- Проверка: `npm run dev -- -p 3300`; `node scripts/shot.mjs http://localhost:3300/ <out> 1440 900 dark 800`,
  МВ: `ENGINE=webkit MOBILE=1 node scripts/shot.mjs http://localhost:3300/ <out> 390 844 dark 700`.
- Публикация (только с согласия): коммит → `git push` → `npm run deploy` → https://ann938.github.io/orbita-lamp/ (репо Ann938/orbita-lamp, noindex).
- В шапке — кнопка питания (`PowerButton`).
- Первый экран — спальня: `public/room/bedroom.jpg` (сгенерировано в Figma, файл «Орбита — спальня»), рисуется фоновым шейдером
  (`ROOM` в LampScene.ts: координаты тумбочки в кадре). Поза `room: 1` у hero; светильник стоит на тумбочке, комнату освещает его свет
  (`uPower`), выключен — лунный полумрак. При прокрутке комната уезжает вверх (`roomShift`) и растворяется в космосе.
  МВ: кадр не «cover», а `ROOM_MOBILE.h` высоты экрана, верх тумбочки — у низа слота hero (`setRoomTop`).
